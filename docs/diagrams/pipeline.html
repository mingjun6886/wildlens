The original wrote to the database only once processing finished, so for the three minutes in between the UI had nothing to render. Writing early and updating in place is what makes a progress indicator possible at all.

04 · Queue semantics

Three things that bite first-time queue users

Each of these is handled explicitly in the Terraform and in the worker. They are listed here because the handling, not the queue itself, is the interesting part.

① The same file processed twice

Standard SQS guarantees at-least-once delivery, not exactly-once. Unguarded, a redelivery means running inference twice and emailing subscribers twice.

Handled by: a conditional write — “only if this record is not already DONE”. The second run catches ConditionalCheckFailedException, logs it, and exits successfully. The property is idempotency.

② The hidden clock that fans out

While a worker holds a message, SQS hides it for the visibility timeout. If that expires before the work finishes, the message is handed to another worker — exactly the runaway the queue was meant to prevent.

Handled by: visibility timeout ≥ 6 × the function timeout. A 900 s function gets 5400 s, set in Terraform with the reasoning in a comment.

③ One bad file blocks the queue

A corrupt image crashes the worker. The message returns, is retried, crashes again — indefinitely, holding up everything behind it.

Handled by: a redrive policy at three attempts, plus a CloudWatch alarm on DLQ depth ≥ 1. docs/runbook.md documents the triage steps.

05 · Cost engineering

Running this on a $100 credit

The interesting risk is not the running cost; it is the resources that bill by the hour whether or not anything happens.

The $32/month trap, avoided deliberately: a great deal of tutorial material puts Lambda inside a VPC because it sounds more secure. A VPC-attached Lambda that needs outbound internet requires a NAT Gateway — $32 a month, billed hourly, whether or not it carries traffic. Nothing here needs a VPC: every service the worker talks to is a public AWS endpoint already gated by IAM. That decision is recorded as an ADR.

Six guardrails: budget alarms at $10 / $25 / $50 · reserved concurrency of 2 · 14-day log retention · ECR lifecycle policy keeping three images · S3 lifecycle expiry at 30 days · terraform destroy between working sessions.

06 · Build plan

Four milestones, each a complete artefact

Ordering principle: whatever is hardest to debug gets built earliest, and in the environment where debugging is cheapest. Inference is proven on a laptop before it ever enters a container, because iterating on a 4.5 GB image costs twenty minutes a round trip.
